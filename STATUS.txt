🚀 HOW TO USE

START SERVER:
  cd c:\Apartment_Rental_Portal\backend
  python manage.py runserver

VISIT PORTAL:
  http://localhost:8000/Portal/

TEST AUTHENTICATION:
  1. Click "Register"
  2. Create new account (username, password)
  3. Auto-logged in to dashboard
  4. Click "Apartments" to browse listings
  5. Click "+ Add Apartment" to create listing
  6. Click "Logout" when done
