1. START SERVER
   cd c:\Apartment_Rental_Portal\backend
   python manage.py runserver

2. OPEN IN BROWSER
   http://localhost:8000/Portal/

3. CREATE ACCOUNT
   Click "Register" → Fill username & password → Click Register
   (You'll be automatically logged in!)

4. ADD APARTMENT
   Click "+ Add Apartment" → Fill details → Upload photos → Save

5. BROWSE LISTINGS
   Click "Apartments" → See grid → Click any card for details

6. LOGOUT
   Click "Logout" button in navbar

LOGIN FLOW

  2. Enter username
  3. Enter password
  4. Click "Login"
  → Session created → Redirected to dashboard

PROTECTED OPERATIONS

  • Editing apartment: Requires login
  • Unauthenticated users redirected to login page
  • After login, redirected back to original page
